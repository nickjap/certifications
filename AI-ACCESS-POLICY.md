
# Automated Access and AI Usage Policy

The repository owner requests that automated systems,
AI agents, crawlers, bots, and scrapers refrain from:

- Accessing or collecting repository content
- Crawling, scraping, or downloading files
- Indexing or ingesting repository content
- Using content for AI training or dataset creation
- Creating embeddings or retrieval indexes from content
- Republishing or redistributing collected content

This request applies to HTML, PDF, PNG, source code,
documentation, and other repository files.

Automated systems should respect the owner's request
and any applicable published crawler-exclusion rules.

This notice expresses the owner's policy preference.
It does not itself provide technical access control.
